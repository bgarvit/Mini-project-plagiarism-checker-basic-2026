Algorithm Transparency

How we measure similarity

PLAGIFY uses a weighted ensemble of proven algorithms. Each serves a specific purpose in detecting different types of overlap.

TF-IDF + Cosine Similarity (40% weight)

  • Unigram + bigram TF-IDF vectorization
  • Sublinear term frequency scaling
  • L2-normalized cosine similarity
  • Robust to document length differences

Token Jaccard (15% weight)

  • Set intersection over union
  • Stopwords removed, lemmatized
  • Exact word matching
  • Fast baseline metric

Shingle Jaccard (3-gram) (15% weight)

  • Consecutive 3-word sequences
  • Catches copied phrases
  • Resistant to word reordering
  • Standard in plagiarism detection

Char 5-gram Jaccard (10% weight)

  • Overlapping 5-character windows
  • Catches typos & partial edits
  • Language-agnostic
  • Detects obfuscation attempts

Sentence Jaccard (10% weight)

  • Best-match per submitted sentence
  • NLTK sentence segmentation
  • Structural similarity
  • Paragraph-level detection

Sentence TF-IDF (10% weight)

  • TF-IDF vectors per sentence
  • Cosine similarity matching
  • Catches paraphrased content
  • Algorithm-tagged passages
